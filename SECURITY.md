# Security Policy

## Reporting a vulnerability

Please report suspected vulnerabilities through GitHub's private vulnerability reporting feature. Do not disclose security issues in public issues, discussions, or pull requests.

Include, when possible:

- the affected version and platform;
- a minimal reproduction;
- expected and observed behavior;
- potential impact;
- suggested mitigation.

You should receive an acknowledgement within seven days. Please allow time for investigation and a coordinated fix before public disclosure.

## Scope

Security-boundary bypasses, unsafe command execution, credential disclosure, path traversal, policy bypasses, and report tampering are in scope. A scanner false negative by itself may be treated as a detection improvement rather than a vulnerability unless it bypasses a documented enforcement guarantee.
